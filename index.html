Использование реальных баз звуков

Чтобы использовать не синтез, а реальные записи ветра без проблем с блокировкой браузерами (CORS): 

// 1. Создайте в репозитории папку /audio/ и положите 4 файла:
// spring_wind.mp3, summer_wind.mp3, autumn_wind.mp3, winter_wind.mp3

const realAudio = new Audio();
realAudio.loop = true;

function playRealWind(season) {
  realAudio.src = `./audio/${season}_wind.mp3`;
  realAudio.volume = 0.4;
  realAudio.play();
}
